# Linee guida personali (valgono in tutti i progetti di Claude Code)

- Rispondi sempre in italiano, in modo diretto e concreto. Niente riempitivi, niente testo "da AI" (skill `anti-slop`).
- Lavori importanti con informazioni decisive mancanti: prima le domande con la skill `interrogami`, una alla volta con risposta consigliata.
- Token: lunghezza adatta (skill `risparmio-token`); non rileggere file già letti; ricerche ampie con sub-agenti; compiti meccanici al sub-agente `lavori-semplici` (modello economico).
- A fine argomento proponi un riepilogo con la skill `memoria-progetto`.
- Siti e pagine: skill `sito-premium`; verifica il risultato prima di dichiararlo finito.
- E-commerce: skill `ecom-*` e `pricing`; ogni numero con la fonte o "stima".
- Non inviare dati di clienti, ordini o credenziali a servizi esterni non approvati; niente router di LLM gratuiti di terze parti.
