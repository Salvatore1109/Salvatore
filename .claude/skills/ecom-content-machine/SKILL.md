# Content machine (1 → 30)

## Metodo
1. **Un contenuto pilastro** (video lungo, demo, articolo).
2. **Ritaglia micro-contenuti**: ogni idea, obiezione, domanda o momento forte diventa un post.
3. **Nativo per piattaforma**: formato, durata, testo e ritmo diversi per TikTok, Reels, Shorts, carosello, Facebook, LinkedIn. Mai lo stesso file ovunque.
4. **Pubblica ogni giorno**.
5. **Raddoppia su ciò che funziona**: dopo 7 giorni guarda i dati, rifai i 2–3 post migliori con nuove varianti di hook.

## Output standard
- Piano settimanale lun–ven: piattaforma · formato · hook (prima frase/3 secondi) · contenuto · CTA · link con UTM.
- Esempi di tipi: hook basati sul problema, "cosa c'è dentro", domanda di un cliente con risposta, routine d'uso, storia del fondatore, carosello "5 segnali che…".
- Per ogni video breve: hook, scaletta a secondi, testo a schermo, didascalia, hashtag pochi e mirati.

Applica la skill `anti-slop`. Se è collegato uno strumento di pubblicazione, prepara bozze ma non pubblicare senza conferma.
