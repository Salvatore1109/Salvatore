# Memoria di progetto

Le chat non si ricordano tra loro: la memoria affidabile è il file **"Decisioni e contesto"** nella conoscenza del Progetto claude.ai.

## A fine argomento: crea il riepilogo
Produci un blocco pronto da incollare nel file, in questo formato:

```
## [data] — [argomento]
Decisioni: 
- ...
Dati e numeri chiave (con fonte):
- ...
File / link prodotti:
- ...
Da fare (chi / quando):
- ...
Questioni aperte:
- ...
```
Massimo 15 righe. Solo ciò che servirà in futuro, niente cronaca della chat.

## Passaggio a una nuova chat
Se la chat è lunga, scrivi anche un **prompt di ripartenza** di 3–5 righe: obiettivo, stato attuale, prossimo passo. L'utente lo incolla nella nuova chat.

## All'inizio di una chat
Controlla prima la conoscenza del Progetto e le chat precedenti (se la ricerca nelle chat è attiva). Usa quel contesto invece di richiedere informazioni già date.
