# Brand + scheda prodotto

## Parte 1 — Brand
1. **10 nomi** brevi e pronunciabili, con dominio .com/.it plausibile.
2. **Verifica rischio marchio**: indica di controllare su EUIPO (TMview) e USPTO; segna rischio basso/medio/alto. Non dichiarare un nome "libero" senza verifica reale.
3. Per i 3 migliori: **3 concetti di logo** (descrizione), **palette con codici HEX**, **coppia di font**, **3 slogan**.

## Parte 2 — Scheda prodotto
| Elemento | Regola |
|---|---|
| Titolo | Amazon ≤ 200 caratteri: Brand + prodotto + caratteristica chiave + variante. Shopify: più corto, leggibile |
| 5 punti elenco | Beneficio in maiuscolo + prova concreta |
| Descrizione | Scritta per mobile: paragrafi brevi, problema → soluzione → prova → garanzia |
| Keyword nascoste | Amazon: ≤ 249 byte, senza ripetere parole del titolo, niente marchi altrui |
| A+ / sezioni pagina | Wireframe dei moduli: hero, benefici, confronto, come si usa, FAQ |
| SEO Shopify | Meta title ≤ 60 caratteri, meta description ≤ 155 |

Usa le parole dei clienti prese dalle recensioni (anche dei concorrenti). Applica la skill `anti-slop`. Nessun claim sanitario o medico non autorizzato.
